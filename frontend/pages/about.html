AI-Based Predictive Farming System

An Explainable AI-Based Crop Recommendation & Agricultural Decision System for Karnataka Farmers

🎯 ಪ್ರಾಜೆಕ್ಟ್ ಉದ್ದೇಶ (Project Purpose)

ಕರ್ನಾಟಕದ ರೈತ ಬಾಂಧವರಿಗೆ ಸರಳವಾಗಿ, ಡಿಜಿಟಲ್ ಜಟಿಲತೆಗಳಿಲ್ಲದೆ, ತಮ್ಮ ಮಣ್ಣಿನ ಪ್ರಕಾರ ಹಾಗೂ ಸ್ಥಳೀಯ ಹವಾಮಾನಕ್ಕೆ ಸೂಕ್ತವಾದ ಬೆಳೆಯನ್ನು ಶಿಫಾರಸು ಮಾಡುವುದು.

🔬 ತಾಂತ್ರಿಕ ಅಡಿಪಾಯ

  • ML Model: Random Forest Classifier (~88.3% test accuracy on multi-crop dataset, with agronomic rule verification).
  • Vision Models: 5x MobileNetV2 deep learning models + Gatekeeper Crop Validator.
  • Explainable AI: ಏಕೆ ಈ ಬೆಳೆ ಎಂಬುದನ್ನು ರೈತರಿಗೆ ವೈಜ್ಞಾನಿಕವಾಗಿ ವಿವರಿಸುತ್ತದೆ (Scientific Rationale).
  • Data Sources: ICAR-NBSS&LUP, UAS Dharwad, UAS Bengaluru, Open-Meteo.
  • Bilingual: ಕನ್ನಡ ಹಾಗೂ ಇಂಗ್ಲಿಷ್.
