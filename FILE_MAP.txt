3. BACKEND (FASTAPI MODULAR ASYNCHRONOUS ARCHITECTURE)
----------------------------------------------------------------------------------------------------
- backend/app/main.py
  * Purpose: FastAPI root application, CORS setup, router aggregation, and static UI mounting.
  * Called by: Uvicorn ASGI server via run.bat.
  * Key Routes: /api/health, / (redirect to /ui/), /ui/ (static mount), /demo-samples (static mount).
- backend/app/core/config.py
  * Purpose: Centralized dynamic path resolution for models, data, and frontend assets.
  * Called by: app/main.py, app/services/*.
- backend/app/api/
  * crop.py        : Routes for /api/recommend (invokes IntegratedRecommendationEngine).
  * disease.py     : Routes for /api/disease/predict and /api/disease/supported-crops.
  * water.py       : Routes for /api/water/feasibility (FAO-56 ETc calculations).
  * market.py      : Routes for /api/market/prices and /api/market/forecast.
  * soil_report.py : Routes for /api/soil-report/extract (PyMuPDF OCR extraction).
  * soil_types.py  : Routes for /api/soil-types/karnataka (soil database lookup).
  * schemes.py     : Routes for /api/schemes (PM-KISAN, Raitha Siri, PMFBY, etc.).
  * weather.py     : Routes for /api/weather/current and /api/weather/advisories.
  * lifecycle.py   : Routes for /api/lifecycle/stages (phenological stage guidelines).
  * economics.py   : Routes for /api/economics/cost-benefit (gross/net return projections).
- backend/app/schemas/
  * farm_profile.py   : Pydantic request models for soil nutrients and farm parameters.
  * recommendation.py : Pydantic response models for candidate rankings and explainability.
  * lifecycle.py      : Pydantic schemas for crop stages and economic budgets.
- backend/app/services/
  * integrated_decision_engine.py : 5-component decision ranking engine (Agronomy + Water + Market + Forecast + Risk). Loads active production models/rf_30_class/rf_final.pkl.
  * disease_service.py            : Deep learning inference manager loading MobileNetV2 models from models/disease_detection/.
  * image_quality_service.py     : Pre-screening validator checking blur, brightness, contrast, and resolution.
  * explainability_service.py    : Feature contribution and Grad-CAM visual attention heatmap generator.
  * water_service.py             : FAO-56 Penman-Monteith crop evapotranspiration (ETc = Kc * ETo) engine.
  * market_service.py            : APMC mandi price provider and harvest forecast model consumer.
  * soil_ocr_service.py          : Digital text and table parser for Soil Health Card extraction.
  * scheme_service.py            : Government subsidy eligibility and criteria matcher.
  * weather_service.py           : Meteorological data and agro-climatic zone advisory generator.
  * lifecycle_service.py         : Package of practices and operational calendar manager.
